C Language Errors & solutions

common errors beginners face while coding in c.

1. Missing Semicolon

Error:: expected ';' before 'return'

Cause:: You forgot to put a semicolon at the end of a statement.

2. Undefined'main'

Error:: Undefined Reference ro 'main'

Cause:: The Compiler couldn't find a proper main() function.

Fix::Make sure your program has int main () function defined properly.

3. Implicit Declaration

\

Error:: Implicit Declaration of functions 'printf'

Cause:: You forgot to include the header file #include <stdio.h>.

Fix:: Always include required header files before using functions.

4. Missing return statement

\

Error:: control reaches and of non-void function

Cause:: Your main() function is of type int but doesn't returna value.

Fix:: Add return 0; at the end of your main() function.

5. Type Mismatch

\

Error:: invalid operands to binary expression ('int' and 'char *')

Cause:: You are trying to perform an invalid operation between different data types.

Fix:: Make sure variable type are compatible during operations.
